# Performance Panel for Google Sheets

Userscript для Google Таблиц: пересчёт книги или листа штатными средствами Google и список самых медленных ячеек с формулами по замерам движка.

**Установка:** [Greasy Fork](https://greasyfork.org/ru/scripts/597075-performance-panel-for-google-sheets) (нужен Violentmonkey или Tampermonkey).

В этом репозитории лежит только собранный скрипт `performance-panel-for-google-sheets.user.js`. Greasy Fork обновляется из него автоматически после каждого коммита. Сообщение коммита становится списком изменений версии.
